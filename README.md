# Louis-website
my personal portfolio website built with html,css and javascript, showcasing my full-stack development and graphic design project

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript (ES6+)
- Responsive Web Design
- Tailwind CSS
- Font Awesome Icons
- Google Fonts
- Leaflet.js (Maps)
- Fetch API (API communication)

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Bcrypt.js (Password hashing)
- Multer (File uploads)
- Nodemailer (Email service)

### Tools & Services
- Git & GitHub (Version Control)
- MongoDB Atlas (Database Hosting)
- Cloudinary (Image Storage)
- Visual Studio Code
- Linux Development Environment

### Design & UI
- UI/UX Design Principles
- Glassmorphism Design
- Responsive Layouts
- Custom Animations
- Graphic Design Assets
